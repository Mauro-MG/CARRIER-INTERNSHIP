How does this product identify pricing options?

Choose the search mode before creating the configuration. This choice is saved with the configuration.

Code Based

Character → option-code matrix

Choose this when catalog characters must be translated into pricing codes such as 1A, 2C, or 5B using a configuration matrix.

Catalog character G
Matrix: G → 1D, 6B
DOCX search: 1D and 6B
 Character Based

Catalog character is the pricing code

Choose this when the character at Position N should be searched directly in the DOCX table for POSITION N.

Catalog Position 14 = 5
DOCX search: 5
