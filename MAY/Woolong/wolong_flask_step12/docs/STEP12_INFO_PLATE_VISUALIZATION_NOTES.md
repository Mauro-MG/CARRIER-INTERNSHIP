# Step 12 — Full Info_Plate visualization

This step converts the Flask MVP from a calculation page into a visual replacement for the Excel `Info_Plate` sheet.

## Goal

The user should only need to type a model number. The app then renders everything currently generated by the Python/VBA migration layer:

- Nameplate / unit summary
- Electrical ratings
- Decoded model options
- Compressor loads
- Motor loads
- Accessory loads
- Accessory MCA/MOCP rows
- Notes
- Errors / warnings
- Complete generated field list
- Raw JSON for debugging

## New files

- `services/info_plate_view.py`
  - Builds a UI-friendly Info_Plate view model from `CalculationResult`.
- `templates/info_plate.html`
  - Main one-page interface.
- `static/info_plate.js`
  - Debounced live calculation using `/api/calculate`.
- `static/style.css`
  - Added dashboard/nameplate visualization styles.

## Changed files

- `app.py`
  - `/` now opens the Info_Plate page.
  - `/calculate` also renders the Info_Plate page.
- `services/output_builder.py`
  - API/template payload now includes an `info_plate` section.
- `templates/index.html` and `templates/results.html`
  - Kept as compatibility wrappers around the new Info_Plate template.

## Important limitation

This page visualizes every field currently available in the Python migration result. It is not yet a pixel-perfect clone of the original Excel sheet layout. As more VBA logic is ported, the new fields will automatically appear in the `complete generated field` and raw JSON sections, and can be promoted into the main visual sections.
